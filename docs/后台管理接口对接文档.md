# 个人博客后台管理接口对接文档

> **Base URL**: `http://localhost:8081/api`（可由 `public/config.js` 的 `apiBaseUrl` 覆盖）
> **数据格式**: `application/json`（分页查询用 query 参数、文件上传用 multipart/form-data，其余 POST/PUT/PATCH 均为 JSON body）
> **唯一基准**: 本文为简化视图，完整约定以《前后台接口整合与评审.md》（V2）为准。用户模块详见《用户模块接口对接文档.md》。

---

## 一、通用约定

### 1.1 统一返回格式

```json
{
  "code": 0,
  "message": "success",
  "data": {}
}
```

- `code`: 0=成功，非0=失败（401=未登录，前端清除登录态并跳转登录页）
- `message`: 描述信息
- `data`: 业务数据，失败时为 null

### 1.2 鉴权方式

- 登录成功后返回 `tokenValue`，存本地存储
- 后台接口（除登录）请求头携带：`satoken: <tokenValue>`
- 前台只读接口（`/article/list`、`/category/list`、`/tag/list`、`/project/list` 等）免鉴权

### 1.3 分页说明

- 请求参数：`current`（默认 1）、`size`（默认 10），均 `@Min(1)`
- 响应 `data`：`{ "records": [], "total": 100, "current": 1, "size": 10 }`

### 1.4 其他约定

- id 全部为 **string**（Long→String，防 JS 精度丢失）
- 时间 ISO-8601，如 `2026-08-04T10:30:00`
- 状态字段 int：文章 `0草稿/1发布/2下线`；用户 `0禁用/1正常`
- 后台路径为单层前缀（无 `/admin`），`/api` 是 context-path，Controller 路径不带 `/api`

## 三、文章管理

### 3.1 管理分页

- **URL**: `GET /article/page`
- **鉴权**: 是

**请求参数**(Query String):

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| current | int | 否 | 页码，默认 1 |
| size | int | 否 | 每页条数，默认 10 |
| keyword | string | 否 | 标题/摘要 模糊搜索 |
| categoryId | string | 否 | 分类 ID |
| tagId | string | 否 | 标签 ID |
| status | int | 否 | 0草稿 1发布 2下线 |

**响应数据**:
```json
{
  "code": 0,
  "message": "success",
  "data": {
    "records": [
      {
        "id": "1",
        "title": "FFmpeg 音视频转码实战",
        "summary": "介绍 FFmpeg 常用命令与优化技巧。",
        "content": "## Markdown 正文",
        "cover": "",
        "categoryId": "4",
        "categoryName": "音视频",
        "tagIds": ["1", "5"],
        "tagNames": ["FFmpeg", "GB28181"],
        "viewCount": 1286,
        "status": 1,
        "createTime": "2026-07-12T09:30:00",
        "publishTime": "2026-07-12T09:30:00"
      }
    ],
    "total": 7,
    "current": 1,
    "size": 10
  }
}
```

> records 含 `content`，编辑回显直接复用管理分页，无需单独后台详情接口。

### 3.2 新增文章

- **URL**: `POST /article`
- **鉴权**: 是

**请求参数**(JSON Body):

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| title | string | 是 | 标题 |
| summary | string | 是 | 摘要 |
| content | string | 是 | Markdown 正文 |
| categoryId | string | 是 | 分类 ID |
| tagIds | string[] | 否 | 标签 ID 列表 |
| cover | string | 否 | 封面图 URL |
| status | int | 是 | 0草稿 1发布 |

**响应数据**: `data` 为新增后的文章对象

### 3.3 编辑文章

- **URL**: `PUT /article/{id}`
- **鉴权**: 是

**请求参数**(JSON Body)：同 3.2，但**不含 status**（状态变更走 3.5）

**路径参数**: `id` (string)

**响应数据**: `data` 为更新后的文章对象

### 3.4 删除文章

- **URL**: `DELETE /article/{id}`
- **鉴权**: 是

**路径参数**: `id` (string)

**响应数据**: `data = null`

### 3.5 变更文章状态（发布/下线）

- **URL**: `PATCH /article/{id}/status`
- **鉴权**: 是

**请求参数**(JSON Body):

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| status | int | 是 | 1发布 / 2下线 |

**响应数据**: `data` 为更新后的文章对象

## 四、分类管理

> 列表复用公开接口 `GET /category/list`（免鉴权，含已发布文章数，按 sort 升序），后台不设独立列表。

- **URL**: `GET /category/list`
- **鉴权**: 否

**请求参数**: 无

**响应数据**: `data` 为分类数组

```json
{
  "code": 0,
  "message": "success",
  "data": [
    { "id": "1", "name": "C++", "sort": 1, "articleCount": 1, "createTime": "2026-01-05T09:12:00" }
  ]
}
```

### 4.2 新增分类

**请求参数**(JSON Body):

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| name | string | 是 | 分类名称（唯一） |
| sort | int | 是 | 排序值 |

**响应数据**: `data` 为新增后的分类对象

### 4.3 编辑分类

- **URL**: `PUT /category/{id}`
- **鉴权**: 是

**请求参数**(JSON Body)：同 4.2

**路径参数**: `id` (string)

**响应数据**: `data` 为更新后的分类对象

### 4.4 删除分类

- **URL**: `DELETE /category/{id}`
- **鉴权**: 是

**路径参数**: `id` (string)

**响应数据**: `data = null`

> 业务限制：该分类下存在文章时不可删除

## 七、文件管理

> 文件存储为本地磁盘：配置 `file.*`、上传目录 `./upload`、静态映射 `/files/**`；图片返回可访问 url（`/api/files/...`）。

### 7.1 分页查询文件

- **URL**: `GET /file/page`
- **鉴权**: 是

**请求参数**(Query String):

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| current | int | 否 | 页码，默认 1 |
| size | int | 否 | 每页条数，默认 12 |
| type | string | 否 | image=图片 file=附件 |
| keyword | string | 否 | 文件名模糊搜索 |

**响应数据**: `data = { records, total, current, size }`，records 元素：
```json
{
  "id": "1",
  "name": "ffmpeg-cover.png",
  "url": "/api/files/2026/07/xxx.png",
  "type": "image",
  "size": 245760,
  "uploadTime": "2026-07-12T09:00:00"
}
```

### 7.2 上传文件

- **URL**: `POST /file/upload`
- **鉴权**: 是
- **数据格式**: `multipart/form-data`

**请求参数**(FormData):

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| file | file | 是 | 上传的文件（支持图片/附件） |

**响应数据**: `data` 为文件对象（同列表元素，图片时 `url` 为可访问地址）

### 7.3 删除文件

- **URL**: `DELETE /file/{id}`
- **鉴权**: 是

**路径参数**: `id` (string)

**响应数据**: `data = null`

## 八、数据统计

### 8.1 仪表盘统计

- **URL**: `GET /stats/dashboard`
- **鉴权**: 是

**请求参数**: 无

**响应数据**:
```json
{
  "code": 0,
  "message": "success",
  "data": {
    "overview": {
      "articleCount": 7,
      "projectCount": 3,
      "viewCount": 4078
    },
    "trend": [
      { "date": "2026-06-16", "views": 320, "articles": 1 }
    ],
    "categoryDist": [
      { "name": "音视频", "value": 2 }
    ],
    "hotArticles": [
      { "id": "1", "title": "FFmpeg 音视频转码实战", "viewCount": 1286 }
    ]
  }
}
```

| 字段 | 类型 | 说明 |
|---|---|---|
| overview | object | 汇总：文章数/项目数/总浏览量 |
| trend | array | 访问趋势（近 7 周） |
| categoryDist | array | 文章分类分布 |
| hotArticles | array | 热门文章 TOP5（id 为 string） |
